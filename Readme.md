# 📈 Börsen-Dashboard mit Streamlit

Automatische Börsenübersicht mit täglicher Aktualisierung für Aktien, ETFs, Indizes und Kryptowährungen.

## Features

- ✅ Automatische Aktualisierung alle 30 Minuten
- ✅ Übersichtliche Tabelle mit allen wichtigen Kennzahlen
- ✅ Interaktive Candlestick-Charts mit gleitenden Durchschnitten
- ✅ Performance-Ranking (Top & Flop 5)
- ✅ Portfolio-Statistiken
- ✅ CSV-Export
- ✅ Responsive Design für Desktop & Mobile
